# Introduction

This section provides an overview of the tools, software, and high-level concepts used throughout our robotics programming workflow. These resources help streamline development, debugging, and deployment processes.

## Tools & Software

| Tool | Purpose |
|------|---------|
| **Phoenix Tuner X** | Configuration and tuning utility for CTRE Phoenix motor controllers |
| **HawkForge** | Custom software for developing subsystems and implementing them |
| **DriverStation** | FRC Driver Station software for robot control and match operation |
| **AdvantageKit** | Logging and replay framework for robot telemetry and debugging |
| **Elastic** | Search and dashboard application for visualization of data and specific toggles |
